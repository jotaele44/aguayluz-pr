# Patillas–Guayama v0.5

Design-only T1 source-coverage and synchronized-admission package.

The package:

- maps every required real-window balance term to public evidence;
- distinguishes direct T1 observations, transformable precursors, public documents, proxies, and missing operator/field evidence;
- uses exact hourly interval alignment and requires 24 admitted hourly slices for a daily balance, matching NOAA Puerto Rico Stage IV QPE cadence without silent temporal subdivision;
- requires both named reservoir tributaries and the separately observed below-dam river outlet to be accounted for;
- rejects provisional, superseded, calibration-unknown, uncertainty-unknown, topology-conflicting, proxy-only, and datum-mismatched inputs;
- keeps all real balance and runtime/interface activation flags false.

No operator request is sent and no real Lago Patillas balance is executed by v0.5.
