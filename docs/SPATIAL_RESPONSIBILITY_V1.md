# AguaYLuz Spatial Responsibility v1

Status: PROVISIONAL / NON-CERTIFYING

AguaYLuz remains authoritative for water, power, hydrology, environmental infrastructure, hazards, gauges, outage/exposure semantics, and domain-specific spatial analysis.

It SHOULD consume federation geometry services for reusable domain-neutral operations while preserving existing passed domain logic.

## Retained ownership
- hydrologic network/navigation semantics
- watershed/water-system relationships
- water/power/environmental asset semantics
- monitoring/event interpretation
- exposure analysis with explicit evidence state

## Delegable spatial primitives
- geometry validation/canonicalization
- CRS transformation
- topology predicates
- canonical municipio/barrio/coastline geometry
- vector-tile publication

## Non-equivalence safeguard
A Spiderweb geometry result does not establish hydrologic causation, outage attribution, exposure, or infrastructure identity. Domain promotion remains an AguaYLuz decision supported by explicit evidence.

## Migration gate
No existing hydrology/infrastructure output is replaced until intersection, geometry delta, row-conservation, stable-ID, null, duplicate, CRS, and positive/negative regression gates pass against the retained baseline.
