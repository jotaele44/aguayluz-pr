# Official EIA archived workbook URLs

The official EIA-860M and EIA-923 distribution paths include both current
`/xls/` and historical `/archive/xls/` locations. The native acquisition client
now admits that one optional archive segment while retaining the exact HTTPS
host, permitted dataset/file types, redirect refusal and credential restrictions.
Nested arbitrary paths, traversal, queries and fragments remain refused.

Positive tests preserve original downloaded bytes and source receipts for an
archived 860M XLSX and archived 923 ZIP. Negative tests prove invalid variants do
not reach the transport. The normal native source-acquisition workflow uses this
same validator; public interfaces, schemas and promotion gates are unchanged.

Supporting uploaded research materials are preserved in a private intake evidence
set. They are not committed as authoritative data. The supplied credential was
not printed, copied into this repository or transmitted while source access was
proxy-blocked. Uploaded scripts were not executed. Original workbooks, original
API response receipts and independent scientific verification remain open gates.

The existing P0, capture-recovery and Federation baselines remain unchanged.
This bounded URL compatibility fix does not certify the electricity platform.
